# City-Life Art List (SEALED — DM ONLY)

> **Superseded for generation by `sealed/art-manifest.md`** (one consolidated list with tiers, final paths and a prompt paragraph per image). This file stays as the city layer's record. Note: Old Abel Fathom is now Old Enoch Fathom (CHG-10).

> Every shop interior, shopkeeper portrait and establishing painting the city-life layer calls for, with file names per the naming rule (`ch##-place-name.jpg`, `npc-###-name.jpg`). Descriptions for the painter are in each source file (the shop's **Interior (painter)** line, or the city's **at a glance** section). Style: `/art/style-bible.md`.
>
> **Spoilers:** an image may be shown to the player only from its **Show from** chapter on (the first chapter the place or person can be met). Mirrowen and Act III images are sealed until then. Shop interiors are painted **without text labels**; signs can be added in the text.
>
> **Reference portraits first** (`/art/portraits/`) for anyone who appears in more than one image. Tier 1 characters' portrait paths match `truth/01`. Tier 2 and provisional NPC paths use the short names below; if the Truth File's owner renumbers a provisional ID (CHG-CY-01), rename the file to match.

## Painting order (suggested)

1. **Act I, home city** (Ch1–Ch5): the Row, the seven magic shops, Willow Lane's merchants, their keepers. These are needed first.
2. **Act II** river and lake towns (Ch4, Ch8–Ch13).
3. **Act III** and Mirrowen (Ch6 Hollowmere-occupied is the exception: it's needed by Ch6).
